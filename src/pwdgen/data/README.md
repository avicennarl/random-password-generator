# Bundled data

## `words.txt`

The passphrase wordlist is the **BIP39 English wordlist** (2048 words, each
4–8 lowercase ASCII letters).

- Source: <https://github.com/bitcoin/bips/blob/master/bip-0039/english.txt>
- Specification: <https://github.com/bitcoin/bips/blob/master/bip-0039/bip-0039-wordlists.md>
- License: MIT (see the [bips repository](https://github.com/bitcoin/bips/blob/master/COPYING))

The same list is shipped to the web build as `web/words.js`.
